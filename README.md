# Fixper

Современный адаптивный сайт сервиса ремонта бытовой и цифровой техники.

## 📋 О проекте

**Fixper** — это веб-сайт сервисного центра, предоставляющего услуги по ремонту бытовой техники, электроники и цифровых устройств. Проект разработан с использованием современных технологий и полностью адаптирован для мобильных устройств, планшетов и десктопов.

## 🚀 Основные возможности

* Адаптивный дизайн (Mobile First)
* Информация о сервисном центре
* Контактные данные и карта
* Список услуг и стоимость работ
* Отзывы клиентов
* Карточки мастеров
* Форма обратной связи
* Поддержка различных способов оплаты
* SEO-оптимизированная структура

## 🛠️ Технологии

* HTML5
* Tailwind CSS
* JavaScript (ES6+)
* Responsive Design
* Flexbox
* CSS Grid

## ⚙️ Установка и запуск

```bash

git clone https://github.com/username/fixper.git

# Перейти в директорию проекта
cd fixper

# Установить зависимости
npm install

# Запустить проект
npm run dev
```
